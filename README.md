# BRP SafeZone downloads

BRP SafeZone is a portable Windows app for private communities, voice rooms,
chat and GPU screen sharing. Sign in with email/password or Google. Live media,
messages and user uploads travel directly between participants.

Download the latest Windows ZIP from [Releases](https://github.com/brurpo/brp-safezone-releases/releases/latest),
extract the complete folder, and run **BRP SafeZone.exe**. Keep its assets,
licenses and libde265.dll beside it. Windows 11 is recommended; no administrator
rights or installer are required.

This is a beta. Version 0.14 and later can check and download updates from this
repository without a GitHub account or token. Earlier versions need one manual
update. Packages include a signed update manifest and SHA-256 checksum.

This repository contains downloadable releases only. The application source
repository remains private. Your profile, account keys and chat history are
never stored here.
