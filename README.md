# BRP SafeZone downloads

BRP SafeZone is a portable Windows app for private communities, voice rooms,
chat and GPU screen sharing. Sign in with email/password or Google. Live voice,
video and shared audio travel directly between participants encrypted. Communities can
keep chat/files on the creator's PC or in the creator's own Cloudflare account.
Members never need the creator's hosting credentials.

Download the latest Windows ZIP from [Releases](https://github.com/brurpo/brp-safezone-releases/releases/latest),
extract the complete folder, and run **BRP SafeZone.exe**. Keep SafeZoneUpdater.exe,
assets, licenses and libde265.dll beside it. Windows 11 is recommended; no administrator
rights or installer are required.

This repository contains downloadable releases only. The application source
repository remains private. Your profile, account keys and chat history are
never stored here.
